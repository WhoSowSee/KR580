# История изменений

## [3.1.0] - 2026-09-07

### Новые возможности

- Добавлено: навигация Tab и Shift+Tab по кнопкам внешних устройств, включая отдельные окна и шестнадцатеричный буфер монитора, с активацией через Enter или пробел и сохранением выделения после нажатия

### Исправления

- Исправлено: указатель стека SP корректно восстанавливается из файлов `.580` и сохраняется при повторной записи
- Исправлено: значения регистров A, B, C, D, E, H, L, W и Z восстанавливаются из файлов `.580` и сохраняются при повторной записи
- Исправлено: сохранение подпрограммы `.krs` не помечает изменения регистров и памяти вне выбранного диапазона как сохранённые
- Исправлено: ошибка записи подпрограммы `.krs` больше не повреждает существующий файл
- Исправлено: диапазон подпрограммы `.krs` определяется по фактически загруженным байтам и используется при последующем сохранении

### Сборка и упаковка

- Исправлено: терминальный запускатель `kr.exe` отображается в Windows под именем KR, а графическое приложение `kr580.exe` сохраняет имя KR580

## [3.0.0] - 2026-09-06

### Несовместимые изменения

- Изменено: исполняемый файл графического приложения переименован из `k580` в `kr580`; обновлены установщик, запускатель, ассоциации и пакеты
- Изменено: публичная функция `file_assoc::is_registered` теперь доступна только на Windows, а `kr -u` на macOS возвращает ошибку неподдерживаемой операции; исправлены имена релизных файлов, владение системной интеграцией, откат ассоциаций Linux и отзывчивость настроек при их применении

### Новые возможности

- Добавлено: значки приложения и документов macOS, описания типов файлов `.580` и `.krs` и метаданные пакета приложения
- Добавлено: назначение KR580 приложением по умолчанию для `.580` и `.krs` из настроек на Linux и macOS

### Исправления

- Исправлено: монитор использует полный растровый шрифт CP866 для кириллицы, псевдографики и остальных байтовых символов
- Исправлено: обработка файловых ассоциаций Windows и регистрация обоих расширений `.580` и `.krs`
- Исправлено: удаление ассоциаций Linux сохраняет обработчики, принадлежащие другим установкам приложения
- Исправлено: регистрация файлов Linux учитывает пользовательские каталоги XDG
- Исправлено: пути исполняемых файлов в записях рабочего стола Linux корректно заключаются в кавычки и экранируются
- Исправлено: значки приложения и типов файлов Linux встроены в приложение и доступны при регистрации ассоциаций
- Исправлено: ошибки обновления баз типов файлов и приложений Linux сообщаются пользователю
- Исправлено: регистрация ассоциаций macOS использует существующий пакет приложения
- Исправлено: открытие документов из Finder обрабатывается через события macOS с проверкой несохранённых изменений
- Исправлено: пакетные приложения используют доступные для записи пользовательские каталоги настроек
- Исправлено: в Snap скрыто недоступное действие изменения системных файловых ассоциаций
- Исправлено: обработчик файлов отображается под единым именем KR580 на Windows и Linux
- Исправлено: фокус, навигация Tab и ввод шестнадцатеричных адресов в диалогах открытия и сохранения подпрограмм; начальное действие Enter соответствует кнопке «Отмена»

### Сборка и упаковка

- Обновлено: описания исполняемых файлов Windows различают приложение, установщик и деинсталлятор
- Обновлено: видимый запускатель Linux отделён от скрытого обработчика файлов, чтобы отключение ассоциаций не удаляло приложение из меню
- Обновлено: Debian-пакет получил зависимости для интеграции с рабочим столом
- Обновлено: установщик и файловые ассоциации macOS используют единый формат пакета `KR580.app`
- Исправлено: ресурсы Windows не компилируются при сборке для других целевых платформ
- Обновлено: регистрация приложения macOS переведена на публичный API Launch Services
- Добавлено: поставка macOS в виде DMG с установкой перетаскиванием `KR580.app` в Applications
- Обновлено: метаданные Linux централизованы в общих шаблонах для приложения, установщика и пакетов
- Обновлено: Snap содержит готовое графическое приложение вместо вложенного установщика
- Добавлено: автоматические проверки системной интеграции Linux и содержимого DMG macOS
- Исправлено: ошибки Clippy на Rust 1.88 и порядок аргументов `lipo` при сборке и проверке DMG macOS

## [1.0.0] - 2026-06-23

### Добавлено

- Настольный эмулятор КР580 с детерминированным состоянием процессора, 64 КиБ ОЗУ, прерываниями, состоянием останова, счётчиками циклов и выполнением по тактам
- Нативный интерфейс на iced с редактированием ОЗУ и регистров, просмотром регистра состояния, выполнением по командам и тактам, а также режимами запуска с заданным темпом и пакетного выполнения
- Окна внешних устройств для монитора, дисковода, жёсткого диска, сетевого адаптера и принтера через типизированные порты `IoBus`
- Версионированные снимки `.580`, загрузка необработанных подпрограмм `.krs`, импорт и экспорт TXT/XLSX, а также экспорт печати в PDF
- Графический установщик и деинсталлятор, средство запуска из терминала, необязательные ассоциации файлов `.580` и `.krs`, переносной и системный режимы установки
- Конвейер выпуска установочных артефактов, Linux-пакетов Debian, Snap-пакетов, артефактов GitHub Actions и GitHub-релизов по тегам
